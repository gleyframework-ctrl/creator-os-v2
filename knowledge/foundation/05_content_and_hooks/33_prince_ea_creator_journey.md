## 2. VIRAL STORYTELLING STRUCTURE

### 2.1 Long-Form Structure

| Element | Description |
|---------|-------------|
| Hook | Start with BANG in first 5 seconds |
| Body | Break into chapters/sections |
| Conflict | The struggle needing resolution |
| Resolution | Satisfying payoff |
| Surprise (Twists) | Unexpected dopamine triggers |
| Foreshadowing | Tease key moments early |
| South Park Method | "This happens, therefore this happens" |
| Payoff | End with powerful insight |
| Call to Action | Direct to next step |

### 2.2 Short-Form Structure

| Element | Description |
|---------|-------------|
| Hook | 1-3 seconds (jump in frame, hard zoom, bold statement) |
| Body | "But, Therefore" format |
| Payoff | Memorable takeaway or twist |
| Prop | Visual metaphor |
| Engagement Boosters | Captions, trending music, pre-frame titles |

### 2.3 Long vs Short Comparison

| Aspect | Long-Form | Short-Form |
|--------|-----------|------------|
| Hook Timing | 15-30 seconds | 1-3 seconds |
| Pacing | Moderate, mixed | Rapid, consistent |
| Focus | In-depth | Single idea |
| Transitions | Smooth | Fast, abrupt |
| Expectation | Time investment | Quick, snappy |

## 5. TITLE FRAMEWORKS

### 5.1 The 7-Step Title Formula

| Step | Rule |
|------|------|
| 1 | Keep it simple (4th grader level) |
| 2 | Build intrigue, interest, curiosity |
| 3 | Be bold and eye-catching |
| 4 | Use uncommon word combinations |
| 5 | Use dates for 20% more views |
| 6 | Use brackets/parentheses for 30% more views |
| 7 | Use click-food, not click-bait |

### 5.2 The 10 Commandments for Testing Titles

| # | Question |
|---|----------|
| 1 | Is the title in verb/action tense? |
| 2 | Does it start a conversation or generate self-interest? |
| 3 | Is it as short as possible? |
| 4 | Is it shareable? |
| 5 | Is it at 4th/5th grade reading level? |
| 6 | Is there a crazy or unexpected word combination? |
| 7 | Is it attention-grabbing, striking, or bold? |
| 8 | Is it shocking or polarizing? |
| 9 | Does it ethically use FOMO? |
| 10 | Does it stimulate emotion? |

## 9. CONTENT TILT

A content tilt is offering a fresh, unexpected perspective on a familiar topic.

**Example:**
- Common: "How to Build an Email List"
- Tilted: "Why Building an Email List Is a Waste of Time (Unless You Do This First)"
