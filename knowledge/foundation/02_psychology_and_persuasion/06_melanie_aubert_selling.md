## 4. THE 4 CONTENT FRAMEWORKS

### 4.1 Framework 1: Educate / Problem Solve

**Purpose:** Pull from Content Groundwork to educate on the real problem.

**Questions to Answer:**
- What do they think is their problem vs what is?
- What do they need to know to disrupt their cycle?
- Where are they wasting time and what is it costing?
- How is your offer THE solution?

**SKD Value Stack:**

| Layer | What They Need | Example |
|-------|----------------|---------|
| See | Visual proof | Screenshot of "Domain Blocked" error |
| Know | Information | The 3-step process to own infrastructure |
| Do | Action | "Comment SYSTEM for free audit" |

### 4.2 Framework 2: Embodiment / Credibility

**Purpose:** Even when about you, make it about THEM.

**Rules:**
- Always tie back to reader's benefit
- Batch ideas
- Use SKD stack

**Example:**
- See: Client dashboard showing 5,000 emails, zero blocks
- Know: "Here's how Ahmed went from burning domains to 200k/month"
- Do: "If you want this too, here's the first step"

### 4.3 Framework 3: Dissolving Resistance

**Purpose:** Address objections before they arise.

**SKD Value Stack:**

| Layer | Example |
|-------|---------|
| See | Testimonial from non-technical client who succeeded |
| Know | "You don't need to be a tech genius. We do it together" |
| Do | "Book a free audit call. No tech knowledge required" |

### 4.4 Framework 4: Brand / Value

**Purpose:** Reinforce brand values and unique expression.

**Brand Values:**
1. Reliability - Your infrastructure won't fail
2. Empowerment - You learn to own it
3. Freedom - Automation frees your time
4. Clarity - No jargon, just simple steps

**SKD Value Stack:**

| Layer | Example |
|-------|---------|
| See | Clean diagram of 3-step process |
| Know | "I teach infrastructure the way I wish I'd learned it" |
| Do | "Follow along. See if my style resonates" |

## 6. PASSIVE SALES STRATEGIES

### 6.1 CFD Method (Calling Forward Desire)

When sharing client wins or embodiment:

| Element | What To Do |
|---------|------------|
| Client Win | Tie back to your offer name and framework |
| Your Embodiment | Tie your wins back to your offers |
| Repetition | Repeat. Your audience doesn't see everything |
| Highlights | Save stories to offer-related highlight |

### 6.2 Stacking Value in Feed

Formula:
- Anchor content with client testimonial OR personal embodiment
- Mention program/offer naturally

### 6.3 Planting Offers Within Offers

In Infrastructure, plant a bonus that gives VIP access.

Seeds desire to ascend.

### 6.4 Checkout Page Flow

**Order Bump Template:**
> Before you go! I wanted to offer you X% off [offer name]!
> 
> [offer tagline / end result]
> 
> Enjoy instant access to X trainings where we cover:
> - [3-5 key points]
> 
> [2-3 client testimonials]

**Income Engine Order Bump:**
> Before you complete VIP purchase, get 20% off Infrastructure Private Deployment!
> 
> Go from automated leads to complete ownership of your outbound system.
> 
> Instant access to 4 hours of training:
> - Private VPS setup step-by-step
> - Postfix configuration for max deliverability
> - Python automation scripts
> - Telegram bot control
> 
> "I went from burning domains weekly to 200k/month in 30 days." - Ahmed

### 6.5 Down-Selling

Use abandoned cart email to offer discounted VIP.

### 6.6 Re-Engagement

VIP members who haven't upgraded after 3 months get personal email with discount.

### 6.7 Word of Mouth

Create spaces you're proud of. Be so good they HAVE to tell others.

## 8. DRIP METHOD FOR STORIES

### 8.1 Two Types of Anchor Content

| Type | Purpose |
|------|---------|
| Main Anchor Content | Core offer overview - repeat daily |
| Supporting Anchor Content | Elaborate on specific part of offer |

### 8.2 The Drip Process

1. Choose a module to zoom in on
2. Choose a framework
3. Follow See, Know, Do
4. Add Supporting Anchor slide
5. Add Main Anchor slide

**Example:**
- Module: Postfix Configuration
- Framework: Educate / Problem Solve
- See: Screenshot of config file with danger setting circled
- Know: "99% ignore this setting - costing them thousands"
- Do: "Join VIP to learn the exact config"
- Supporting: Deep dive on that setting
- Main: "Infrastructure Private Deployment"

## 9. CAROUSEL POST FORMATS

### 9.1 Magic Number 3 Rule

Only 3-4 supporting points. More lacks specificity.

Reveal answer on slide 2, not slide 1.

### 9.2 Format 1: Educate / Problem Awareness

| Slide | Content |
|-------|---------|
| 1 | Hook |
| 2 | First Point |
| 3 | First Solution |
| 4 | Second Point |
| 5 | Second Solution |
| 6 | Third Point |
| 7 | Third Solution |
| 8 | Wrap up and loop back to hook |

### 9.3 Format 2: Problem-Awareness

| Slide | Content |
|-------|---------|
| 1 | Hook |
| 2 | Highlight unique brilliance |
| 3 | First Point |
| 4 | Second Point |
| 5 | Third Point |
| 6 | Results in Contrast |
| 7 | Loop back to hook |
| 8 | Pattern interrupt |
| 9 | Call out and loop to brilliance |
| 10 | CTA |

| Slide | Content |
|-------|---------|

| 4 | First Point in-depth |
| 5 | Second Point |
| 6 | Dissolve Resistance |
| 7 | Third Point |
| 8 | Fourth Point |
| 9 | Loop back to resistance |
| 10 | CTA |

|-------|---------|
