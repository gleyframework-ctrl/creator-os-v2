## PART 4: BUSINESS CATEGORIES & FOLLOW-UP ASSETS

### 4.1 Retail Sales Process

**Retail Reality:**
- Many don't have email lists
- Aren't great at tracking
- Owner rarely hands-on
- Spending on ads with poor results

**Where to Start:**
- Only take them if they have list OR huge volume
- Use Finding Hidden Money process
- Figure out what worked best
- Have them do it again

**Retail Checklist:**

| Category | Metrics |
|----------|---------|
| Big Picture | Monthly ad spend, gross revenue, net revenue |
| Sales Process | Greeting script, upsell script, contact info capture |
| Process Numbers | Call to appointment ratio, show rate, close rate |

### 4.2 E-Commerce Sales Process

**E-Commerce Reality:**
- Big pain points: increased costs, supply chain, thinning margins
- They think problem is Amazon
- Real problem: not doing basic things
- Even billion-dollar brands leave money on table

**Typical Process:**
```
Ads → Product-specific lander → Checkout → Done
```

**What's Missing in 99%:**
- Two-step order forms
- Order bumps
- One-click upsells
- Downsells
- Exit intent pop-ups
- Abandoned cart sequences
- Deadline sequences

### 4.3 Info Business Sales Process

| Type | How It Works |
|------|--------------|
| Event-based ascension | Free/cheap event → Upsell |
| Loss leader ascension | Lead with SLO → Ascend |
| Product suite | Multiple products (no ascension) |
| The main thing | One specific, single offer |
| Product-based ascension | Loss leader → Mid-tier → Main thing |

### 4.4 Professional Services

| Process | Description |
|---------|-------------|
| One-to-many | Live events, lunch and learns, webinars |
| Opt-in to email saturation | Lead magnet → email sequence → call |
| Advertise to direct application | Ad → application → schedule |

### 4.5 AOV Toolkit

| Tool | Description |

## PART 6: COLLABORATIVE CLOSE & OPERATIONS

### 6.1 The Collaborative Close (7 Questions)

| # | Question |
|---|----------|
| 1 | "Where do you want to be a year from now?" (Revenue, time, net profit) |
| 2 | "Awesome! Where are you now?" |
| 3 | State the gap (don't dwell on it) |
| 4 | "What are you doing now to get the results you're getting?" |
| 5 | Dig deeper: "What made you reach out now? How are you getting customers?" |
| 6 | "Are there any recurring problems or worries bugging you?" |
| 7 | "What's the most profitable thing you've ever done?" |

### 6.2 Setting the Stage

```
"I don't have a sales script or anything. Here's what I was hoping we could do – 
I'd like to understand where you are, what you're dealing with, and see if I can 
help. Is that okay with you?"
```

### 6.3 Handling Objections

**If they hesitate:**

```
"It's totally OK if you don't want to work together. But do you mind me asking 
where the hesitation comes from?"
```

**If worried about cost:**

```
"OK, no problem. I'm not going to try to pressure you into this. Is it OK if I 
ask you something though? Do you think that in the long run, you'd make more by 
doing this than if you didn't do it? Then out of curiosity, where's the hesitation 
coming from?"
```
